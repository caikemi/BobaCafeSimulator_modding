[Compatibility status] This folder preserves the legacy API v1 Windows MP3 example only.

Boba Mod API v3 does not yet connect BobaModMusicAsset to the internal playback registry and does not expose arbitrary MP3/file access. Do not add an apiVersion 3 mod.json or use main.lua as a new-mod template.

Older game builds may continue to load it through the manifest-free compatibility path; internal changes can affect it. New authors should read README.md here and the repository migration guide.
