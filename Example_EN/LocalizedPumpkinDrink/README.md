# LocalizedPumpkinDrink (legacy API v1 only)

[Back to examples](../README.md) | [中文](../../Example_ZH/LocalizedPumpkinDrink/)

This folder demonstrates runtime switching of legacy mod metadata and drink text. It intentionally has no `mod.json`.

API v3 currently has one manifest `name` and no public culture query, string-table registration, or runtime localization service. It is not a new-mod template. For now, a v3 author should publish target-language text variants and explain them on the Workshop page.

The old script may continue through API v1 compatibility, without v3 sandbox or rollback guarantees.
