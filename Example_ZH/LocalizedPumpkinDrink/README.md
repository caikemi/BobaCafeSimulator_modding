# LocalizedPumpkinDrink（仅旧 API v1）

[返回示例索引](../README.md) | [English](../../Example_EN/LocalizedPumpkinDrink/)

此目录演示旧环境中按运行时语言切换 MOD 元数据和饮品文本，故意没有 `mod.json`。

API v3 当前只有一个清单 `name`，尚未公开 culture 查询、字符串表注册或运行时本地化服务。因此它不是新 MOD 模板。需要 v3 的作者目前应为目标语言分别发布文本版本，并在工坊页面说明。

旧脚本可以继续走 API v1 兼容路径，但不享受沙箱和回滚保证。
