# CustomBGM（仅旧 API v1）

[返回示例索引](../README.md) | [English](../../Example_EN/CustomBGM/)

此目录保留旧 Windows MP3 MOD 的兼容示例，故意没有 `mod.json`。它依赖旧高权限内部接口，不是 BaseInstall API v3 模板。

当前 v3 的 `BaseInstallModMusicAsset` 尚未接入游戏音乐播放注册表，也没有公开任意 MP3/文件访问接口。因此现在不能安全迁移；不要给本目录添加虚假的 API 3 清单。

旧玩家版本若仍能运行，可继续使用，但游戏内部实现变化可能影响兼容性。
