# Apple Juice Bucket (20L)

Adds an independent 20-liter apple juice bucket. New buckets arrive full of apple juice, pour only into cups, and have a dark green exterior.

- Maximum capacity: 20L / 20000mL.
- Initial contents: 20L of apple juice.
- Price, unlock level, and delivery behavior inherit the current built-in bottled-water bucket.
- Found under Goods → Ingredients; preserves the original bucket.
- Saves retain the remaining liquid without refilling it.
- Includes a product icon and Workshop cover; reuses game Blueprints, model, and materials without an additional asset PAK.

Requires API v3 `RegisterItem` and a host build with the 2026-10-26 shop-enumeration, direct-delivery identity, initial-content, and precise-save fixes. The in-game name is 苹果汁桶（20L）, with a Chinese description. All multiplayer peers need the same version; the room check compares Mod IDs/order but not versions or content hashes. Keep the mod enabled for saves containing this product.
